# lang-combat

A German-learning text adventure for Android. You explore Zork-style rooms and act only by typing German;
mistakes are answered in-world by the game, and each floor unlocks a new grammar feature. Fully offline.
Built with Vite, React, TypeScript and Capacitor.

## Develop
- `npm run dev` - run in the browser
- `npm test` - Vitest suite
- `npm run lint` / `npm run build`

Android release builds: see [docs/android-release.md](docs/android-release.md).
